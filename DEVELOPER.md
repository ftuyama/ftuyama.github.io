# Developer guide

Instructions for setting up and working on this repository locally.

## Run the project

Install dependencies:

```bash
npm install
```

Run the dev server (Vite):

```bash
npm run dev
```

Then the app should be available at <http://localhost:5173>

## Lint

```bash
npm run lint
```

## Type check

```bash
npm run typecheck
```

## Build

```bash
npm run build
```

## Running tests

Validate URLs and image formats using:

```bash
npm test
```
